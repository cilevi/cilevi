# Reporting a security problem

If you find a security hole in Cilevi, the Cilevi website or the way licence keys are sold and checked, please tell us privately first. Do not open a public issue or discussion about it.

Write to **support@cilevi.com** with the word **Security** at the start of the subject. Please include:

- what the problem is and what someone could do with it,
- the steps to show it, and
- your Cilevi version (Studio, **Menu**, **About Cilevi**) and Windows version, if it is in the app.

A person reads every message and replies to you. We will tell you when it is fixed, and we are glad to thank you by name in the release notes if you would like that.

Please do not test against other people's accounts or data, and do not run tests that could slow down or break cilevi.com for others.
